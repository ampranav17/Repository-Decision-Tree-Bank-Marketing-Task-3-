# Repository-Decision-Tree-Bank-Marketing-Task-3-

🔹 Objective

To build a machine learning model that predicts whether a customer will subscribe to a bank term deposit.

🔹 Work Done

Used the Bank Marketing Dataset

Encoded categorical variables

Split data into training and testing sets

Built a Decision Tree Classifier

Evaluated model performance using accuracy and classification metrics

🔹 Key Insights

Call duration is a major factor

Previous campaign success increases subscription chances

Financial factors like housing and personal loans influence decisions

🔹 Tools Used

Python, Pandas, Scikit-learn, Matplotlib

🔹 Outcome

Learned supervised machine learning, model training, and evaluation techniques.
